Report instructions
Run the full project first:
```bash
python run\_project.py --name "Your Name" --student-id "Your Student ID"
```
After running, this folder will contain:
```text
Final\_Project\_Report.md
Final\_Project\_Report.docx
```
The report includes:
Project title
Student name and ID
Dataset name and source link
Project objective and analytical questions
Dataset description
Data cleaning and preparation
Feature engineering
Analysis and visualizations
Key findings
Limitations
Conclusion
The figures in the report are created from the actual analysis and saved in:
```text
outputs/figures/
```
